PWA

Progressive Web Applications, PWAs, are a website application that aims to give each user a similar experience. One way this is accomplished is by the responsive design to each different type of device or browser. Another capability is that PWAs have progressive enhancement that means that newer devices benefit from the additional enhancements overtime as the application progresses. This still allows all users to have access while allowing the opportunity to improve with technology and gain additional features.


Additionally, PWAs are available offline using service workers that cache the users content. Similarly, the web application aims to provide an experience that is similar to an application. This means being available, consistent, smooth, and fast in its interactions with the users. Some features that PWAs and apps both have are push notifications, updates, and offline availability. Ultimately PWAs are important for closing the gap between web and native.
